What this project actually found

Two limiter backends, cross-verified against each other

SQLite and Redis-Lua implement the same token bucket and are checked by one conformance suite. Two implementations that agree is evidence; one implementation is an assumption.

Fail open is a product decision before it is a technical one

Failing closed turns a Redis outage into a total outage and makes a protective control the single point of failure. The limiter fails open, deliberately, and the reasoning is written down.

Refusing javascript: and internal hosts is a security control

A shortener that accepts javascript: becomes an XSS laundering service, and one that accepts link-local addresses becomes an SSRF pivot. Both are refused at create time.

A circuit breaker added because a drill found the problem

The breaker is not decoration. A scripted failure drill produced the behaviour it fixes, and the fix was then measured.
